# Pet Me 64

Commodore's display font: **Pet Me 64** by Kreative Software (Kreative Korporation), the Commodore 64's
character set as a TrueType font, from <https://www.kreativekorp.com/software/fonts/c64/>.

It is here under the Kreative Software Relay Fonts Free Use License 1.2f, in `FreeLicense.txt` verbatim: it
may be embedded and given away free of charge with that licence and credit to Kreative Software, and may not be
sold or modified. `PetMe64.ttf` is the file from Kreative's `petme.zip`, unchanged (not subset or converted);
`.gitattributes` keeps both files byte for byte.
